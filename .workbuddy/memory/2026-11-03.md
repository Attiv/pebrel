## 推送问题：换电脑后 HTTPS 认证失败

- 现象：`git push` 走 HTTPS，要求输入 GitHub 用户名和密码，输账号登录密码报错。
- 原因：GitHub 2021-08-13 起停用账号密码做 Git 认证，HTTPS 需 Personal Access Token。
- 已解决：本机 `~/.ssh/id_ed25519` 已登记在 GitHub 账号 `Attiv` 名下，直接把 origin
  从 `https://github.com/Attiv/pebrel.git` 改为 `git@github.com:Attiv/pebrel.git`，
  推送成功（`3ec40de7..670254f5 develop -> develop`）。
- 结论：本机一律用 SSH 地址，不再用 HTTPS 推。
