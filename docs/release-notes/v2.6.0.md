# Pebrel 2.6.0

## English

This fork release aligns its package version with upstream Pebrel 2.6.0 and integrates the latest upstream main branch. Beyond the upstream fixes listed below, this merge adds direct program launches in resident tabs, agent-raised notifications, Command Code support, the Niu shell import, explicit string key bindings and native macOS notifications. Fork features are preserved: AI command completion remains off by default, explicit AI commands keep priority over background predictions, tab titles can keep the local directory or SSH host, and automatic command output views can be turned off.

This customized fork release provides Windows x64/ARM64 installers and portable ZIPs plus a macOS Apple Silicon DMG. macOS retains its Preview label and ad-hoc signing; these packages are not notarized. macOS Intel, Linux, Android and relay packages are outside this release's scope.

### Added

- Added direct program launches in resident tabs: `pebrel tab new` and the `ctl new-tab` control command accept a program with literal arguments, so a script can start a command in a new tab of an existing window instead of typing into a shell.
- Added `pane.notify` to the Runtime API, so an agent can play the configured bell and show a message through the notification center, for example when an SSH key needs a touch.
- Added recognition for the Command Code CLI, including resume and fork, next to the other supported agents.
- Added Niu (niubash's `niu.exe`) to the terminal directory importer. Imported Niu profiles appear in the default shell picker and launch with `--login -i`.
- Added explicit string actions to custom key bindings, so a shortcut can send fixed text or an exact control sequence instead of only a named action.
- Added native macOS notifications: notices raised while Pebrel is in the foreground now reach Notification Center instead of only the in-app toast.

### Fixed

- Fixed commands typed with a leading space entering Pebrel's command history.
- Fixed command history always writing new records to disk. Set `command_history_persist=0` in `pebrel_settings.txt` and restart to keep new records in memory only.
- Fixed command history records being lost when several Pebrel instances save at the same time.
- Fixed Runtime discovery files on Linux and macOS so that only the owner can read them, and generated Runtime access tokens from the operating system's secure random source.
- Fixed SSH fallback applying a later jump host even when an earlier `ProxyCommand none` already disables the proxy.
- Fixed redundant shell discovery at startup and when opening a pane; a cached shell is checked before launch.
- Fixed the updater selecting an empty installer upload when a matching package was available.
- Fixed mouse-wheel coordinates appearing at the Bash prompt after a foreground program is killed.
- Fixed the agent session index ignoring `PEBREL_CONFIG_DIR`, so each profile keeps its own hook session index.
- Fixed Git worktree creation and cleanup for repositories whose directory names end with a space or newline.
- Fixed local OSC 8 file links whose identifiers were corrupted by a UTF-8 `0x9C` collision, and preserved explicit link identities across hard wraps.

### Improved

- Improved shell startup: shell discovery is cached per process instead of being rescanned at every launch.
- Improved command history persistence: records are flushed on a background worker instead of the interface thread.
- Improved terminal image support: PNG transfers, graphics control sequences and the reader-hint header field are accepted more broadly, and SIXEL output keeps working.

## 中文

本定制分支把包版本对齐到上游 Pebrel 2.6.0，并整合了上游 main 分支的最新代码。除下面列出的上游修复外，本次合并还带来常驻标签页里的直接程序启动、Agent 主动通知、Command Code 支持、Niu Shell 导入、显式字符串键位以及 macOS 原生通知。fork 自有功能全部保留：AI 命令补全仍默认关闭，显式 AI 命令优先于后台预测，标签标题可保留本地目录名或 SSH 主机名，命令输出自动视图可以关闭。

本定制分支提供 Windows x64/ARM64 安装器与便携 ZIP，以及 macOS Apple Silicon DMG。macOS 保留 Preview 标识和 ad-hoc 签名，未进行公证。本次不发布 macOS Intel、Linux、Android 或 relay 包。

### 新增

- 新增常驻标签页中的直接程序启动：`pebrel tab new` 与 `ctl new-tab` 控制命令可以带上程序及其字面参数，脚本因此能在已有窗口中新开标签页运行命令，而不必向 Shell 输入文本。
- 新增 Runtime API 的 `pane.notify`，Agent 可触发已配置的响铃闪烁或声音，并通过通知中心显示消息，例如需要触碰 SSH 密钥时。
- 新增对 Command Code CLI 的识别，支持恢复与分叉，与其他受支持的 Agent 并列。
- 终端目录导入支持 Niu（niubash 的 `niu.exe`）。导入后的 Niu 配置会出现在默认 Shell 下拉中，以 `--login -i` 启动。
- 新增自定义键位的显式字符串动作，快捷键可以直接发送固定文本或精确的控制序列，而不只限于具名动作。
- 新增 macOS 原生通知：Pebrel 在前台时产生的提醒会进入通知中心，而不再只显示应用内提示。

### 修复

- 修复以空格开头的命令被写入 Pebrel 命令历史的问题。
- 修复命令历史总是将新记录写入磁盘的问题。在 `pebrel_settings.txt` 中设置 `command_history_persist=0` 并重启，新记录仅保留在内存中。
- 修复多个 Pebrel 实例同时保存命令历史时记录丢失的问题。
- 修复 Linux 和 macOS 的 Runtime 发现文件权限，仅允许文件所有者读取；Runtime 访问令牌改用系统的安全随机源生成。
- 修复 SSH 回退解析在前面的 `ProxyCommand none` 已关闭代理时，仍套用后续跳板机的问题。
- 修复启动和打开窗格时重复扫描 Shell 的问题；启动前会检查缓存中的 Shell 是否仍可用。
- 修复更新器误选空安装包的问题；有可用的匹配安装包时会选用可用包。
- 修复 Bash 前台程序被强制结束后，滚动滚轮会向提示符输入鼠标坐标的问题。
- 修复 Agent 会话索引忽略 `PEBREL_CONFIG_DIR` 的问题；各配置目录分别保存和读取自己的 Hook 会话索引。
- 修复仓库目录名以空格或换行结尾时，Git 工作树无法创建和清理的问题。
- 修复本地 OSC 8 文件链接的标识符被 UTF-8 `0x9C` 碰撞破坏的问题，并在硬换行后保留显式链接身份。

### 改进

- 改进 Shell 启动：Shell 发现结果按进程缓存，不再每次启动都重新扫描。
- 改进命令历史持久化：记录改由后台工作器写入，不再占用界面线程。
- 改进终端图像支持：更广泛地接受 PNG 传输、图形控制序列与读端提示头字段，同时保留 SIXEL 输出。
