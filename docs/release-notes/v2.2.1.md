# Pebrel 2.2.1

## English

### Added

- Added: Terminal label badges providing live status indicators for active sessions and commands, with dedicated appearance settings and reset support.
- Added: Reopen closed tab / undo tab closure (Cmd+Z on macOS or action dispatch) restoring the closed tab and pane layout at its original position with preserved session metadata.
- Added: macOS command line editing shortcuts (Cmd+Delete for line clear, Cmd+Left/Right for line start/end navigation, Option+Delete for word backward kill) matching native macOS terminal conventions.
- Added: SSH remote port forwarding alongside local port forwarding with direction-aware forward management.
- Added: Interaction motion gating via appearance animation settings, honoring system Reduce Motion preferences while keeping keyboard navigation instantaneous.

### Fixed

- Fixed: Restored shell-owned input modes and keyboard stacks at authoritative command boundaries, preventing protocol writes after shell exit or SSH disconnection without disrupting active AI sessions.
- Fixed: Persist and restore native window geometry and display bounds across application restarts independently of tab restoration.
- Fixed: OpenSSH bracketed loopback forward syntax ([127.0.0.1]:port and IPv6 addresses) resolved from ssh -G including Include file expansion.

### Improved

- Improved: Terminal render color resolution isolated into a lifecycle-owned submodule to keep element footprint within architecture line limits.
- Improved: Settings search and appearance controls updated with responsive transitions and verified reset isolation.

## 中文

### 新增

- 新增：终端状态标签徽章（Terminal Label Badges），为活动会话和命令提供实时状态指示，并在外观设置中支持独立开关及重置。
- 新增：重新打开已关闭标签页/撤销关闭（macOS 上为 Cmd+Z 或对应操作），按原始位置与窗格布局恢复关闭的标签页并保留会话元数据。
- 新增：macOS 原生行编辑快捷键支持（Cmd+Delete 删除至行首、Cmd+Left/Right 跳转行首/行尾、Option+Delete 向后删除单词），符合 macOS 原生终端交互惯例。
- 新增：SSH 远端端口转发（RemoteForward）及方向感知的端口转发管理，与本地端口转发统一协同。
- 新增：交互动效受外观动画设置与系统“减弱动态效果”偏好统一控制，键盘操作保持即时响应。

### 修复

- 修复：在权威命令边界恢复 Shell 独占输入模式与键盘协议栈，并在 Shell 退出或 SSH 断开后阻止协议写入，不影响活动 AI 会话或备用屏幕提示。
- 修复：应用重启时独立于标签页恢复持久化并还原原生窗口尺寸与屏幕位置。
- 修复：支持解析 ssh -G 及 Include 展开中的 OpenSSH 中括号形式回环转发与 IPv6 地址（如 [127.0.0.1]:port）。

### 改进

- 改进：终端渲染颜色解析逻辑解耦至生命周期独立的子模块，保持终端渲染元素符合既有行数预算规范。
- 改进：设置搜索与外观面板动效平滑过渡，确保配置重置测试与隔离验证通过。
