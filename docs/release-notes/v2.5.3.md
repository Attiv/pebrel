# Pebrel 2.5.3

## English

This fork release aligns its package version with upstream Pebrel 2.5.3 while keeping the fork's own features and the integration fixes from the upstream main branch. AI command completion remains off by default, and explicit AI commands keep priority over background predictions.

This customized fork release provides Windows x64/ARM64 installers and portable ZIPs plus a macOS Apple Silicon DMG. macOS retains its Preview label and ad-hoc signing; these packages are not notarized. macOS Intel, Linux, Android and relay packages are outside this release's scope.

### Added

- Synced the upstream main branch and adopted the 2.5.3 release metadata, including the Windows option to keep existing PowerShell `ls`, `ll` and `dir` aliases with `builtin_ls=0`.

### Fixed

- Restored the settings-row modified indicator and the Luau runtime refusal handling left incomplete by the upstream merge, so all three desktop platforms build again.

### Improved

- Explicit AI command requests can use the full inference budget while background suggestions stay limited, so an open SSH session no longer prevents a later explicit request in another tab.

## 中文

本定制分支把包版本对齐到上游 Pebrel 2.5.3，同时保留 fork 自有功能与上游 main 分支的整合修复。AI 命令补全仍默认关闭，显式 AI 命令优先于后台预测。

本定制分支提供 Windows x64/ARM64 安装器与便携 ZIP，以及 macOS Apple Silicon DMG。macOS 保留 Preview 标识和 ad-hoc 签名，未进行公证。本次不发布 macOS Intel、Linux、Android 或 relay 包。

### 新增

- 同步上游 main 分支并采用 2.5.3 发布元数据，包括 Windows 上通过 `builtin_ls=0` 保留 PowerShell 原有 `ls`、`ll`、`dir` 别名的选项。

### 修复

- 修复上游合并后设置行「已修改」标记与 Luau 运行时拒绝处理的残留，三个桌面平台恢复构建。

### 改进

- 显式 AI 命令可使用完整推理预算，后台建议仍受限；开启 SSH 会话后切到其他标签也能正常发起显式请求。
