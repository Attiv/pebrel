# Pebrel 2.5.0

## English

This release adds natural-language command search and separately opt-in AI command completion for integrated local shells.

This customized fork release provides Windows x64/ARM64 installers and portable ZIPs plus macOS Apple Silicon/Intel DMGs. macOS retains its Preview label and ad-hoc signing; these packages are not notarized. Linux, Android and relay packages are outside this release's scope.

### Added

- After selecting a command AI provider and model in Settings, press Cmd+Shift+A on macOS or Ctrl+Shift+A on Windows at an integrated local zsh, Bash 4+ or PowerShell prompt to search for a command in natural language. The current draft becomes the query; Enter generates, Tab adopts without running, and Esc restores the original draft.
- Enable AI command suffix completion separately; it is off by default. With local completion enabled, a verified local prompt can suggest the rest of a nonempty command after 500 ms idle when local sources have no useful candidate. Suggestions carry an AI marker, Tab/Right Arrow follow the selected completion mode, and Enter is still required to execute.

### Improved

- Command AI uses its own provider/model selection without changing the Agent model or next-prompt prediction settings. Only the current input, OS and shell type are sent to the selected provider. WSL and SSH are not supported by command search or AI suffix completion in this release.

## 中文

本版为已集成的本地 Shell 新增自然语言命令搜索，以及需单独开启的 AI 命令后缀补全。

本定制分支提供 Windows x64/ARM64 安装器与便携 ZIP，以及 macOS Apple Silicon/Intel DMG。macOS 保留 Preview 标识和 ad-hoc 签名，未进行公证。本次不发布 Linux、Android 或 relay 包。

### 新增

- 在设置中选择命令 AI 服务商和模型后，可在已集成的本地 zsh、Bash 4+ 或 PowerShell 提示符处按 Cmd+Shift+A（macOS）或 Ctrl+Shift+A（Windows），用自然语言搜索命令。当前草稿会带入为搜索词；Enter 生成、Tab 采用但不执行、Esc 恢复原草稿。
- AI 命令后缀补全需单独开启，默认关闭。启用本地补齐后，在已验证的本地提示符中，非空命令空闲 500 毫秒且本地来源没有合适候选时，可显示带 AI 标识的后缀。Tab/右方向键沿用当前补齐模式，仍需按 Enter 执行。

### 改进

- 命令 AI 使用独立的服务商和模型选择，不改变 Agent 主模型或下一条消息预测设置。仅当前输入、操作系统和 Shell 类型会发送给所选服务商。本版命令搜索及 AI 后缀补全暂不支持 WSL 和 SSH。
