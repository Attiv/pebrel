# Pebrel 2.5.6

## English

This fork release aligns its package version with upstream Pebrel 2.5.6 and integrates the latest upstream main branch, while keeping the fork's own features. AI command completion remains off by default, and explicit AI commands keep priority over background predictions.

This customized fork release provides Windows x64/ARM64 installers and portable ZIPs plus a macOS Apple Silicon DMG. macOS retains its Preview label and ad-hoc signing; these packages are not notarized. macOS Intel, Linux, Android and relay packages are outside this release's scope.

### Added

- Inline Sixel images in desktop terminal panes: programs that emit Sixel can display images in place, alongside the existing OSC 1337 and Kitty image protocols. This comes from the upstream main branch.

### Fixed

- Kept the fork's ended-session mouse and paste guard and its saved window geometry restore from regressing during the upstream merge; both behaviors remain enforced in this build.

### Improved

- AI command hooks now wait for a local connection to become readable instead of sleeping on a fixed interval, reducing idle work without changing shutdown responsiveness.

## 中文

本定制分支把包版本对齐到上游 Pebrel 2.5.6，并整合了上游 main 分支的最新代码，同时保留 fork 自有功能。AI 命令补全仍默认关闭，显式 AI 命令优先于后台预测。

本定制分支提供 Windows x64/ARM64 安装器与便携 ZIP，以及 macOS Apple Silicon DMG。macOS 保留 Preview 标识和 ad-hoc 签名，未进行公证。本次不发布 macOS Intel、Linux、Android 或 relay 包。

### 新增

- 桌面终端新增 Sixel 行内图片：程序输出 Sixel 图像时可直接显示在终端里，与已有的 OSC 1337、Kitty 图片协议并存。该功能来自上游 main 分支。

### 修复

- 在合并上游代码时保留了 fork 的会话结束后鼠标/粘贴输入拦截与已保存窗口几何恢复，两项行为在本版本中仍然生效，未发生回退。

### 改进

- AI 命令钩子改为等待本地连接可读，而不是按固定间隔休眠；减少空闲时的无效工作，关闭时的响应速度不变。
