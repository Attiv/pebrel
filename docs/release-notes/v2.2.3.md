# Pebrel 2.2.3

## English

### Fixed

- Fixed: Terminal tool badges follow the current foreground Agent rather than a retained resume identity, and stop trusting process evidence that has been disproved.
- Fixed: Clearing or remapping the reopen-tab shortcut preserves native text Undo and Redo in input fields and file editors.
- Fixed: Clicking the already-selected tab returns keyboard focus to its content, including after leaving Settings.
- Fixed: Undoing the closure of a remote document or merge view no longer unexpectedly reopens an older unrelated tab.
- Fixed: Native CMD recognizes a fresh prompt after the terminal parser has already restored shell input modes, without getting stuck in a running state.

## 中文

### 修复

- 修复：终端工具徽章跟随当前前台 Agent，而不是残留的会话恢复身份；进程证据被反证后不再作为徽章依据。
- 修复：清除或改绑“重新打开已关闭标签页”快捷键后，输入框和文件编辑器的原生撤销、重做仍然可用。
- 修复：点击已选中的标签页会将键盘焦点交还给其内容，包括退出设置页后的场景。
- 修复：撤销关闭远程文档或合并视图时，不再意外恢复更早关闭的无关标签页。
- 修复：终端解析器已恢复 Shell 输入模式后，原生 CMD 能识别新的提示符，不再卡在运行中状态。
